# Pastelería Delicia - Blueprint

## Overview

Pastelería Delicia is a charming Flutter application that allows users to browse a delightful selection of pastries and cakes, add them to a shopping cart, and place orders. The app is designed with a clean and modern user interface, featuring a soft and inviting color palette. It integrates with Firebase for backend services, including user authentication, product catalog management, and order processing.

## Features

*   **User Authentication:** Customers can sign up and log in to their accounts, enabling a personalized shopping experience.
*   **Product Catalog:** A visually appealing grid displays all available pastries and cakes, with high-quality images and concise descriptions.
*   **Shopping Cart:** Users can add and remove items from their cart, with real-time updates on the total price.
*   **Checkout Process:** A streamlined checkout form allows customers to enter their shipping information and place an order.
*   **Order History:** Users can view a list of their past orders, including details such as the order date, total amount, and status.
*   **State Management:** The app uses the `provider` package for efficient state management, ensuring a smooth and responsive user experience.
*   **Routing:** The `go_router` package handles navigation, providing a seamless flow between different screens.

## Design

*   **Color Palette:** The app features a soft and inviting color palette, with a primary color of pink (`#F9CADA`), a secondary color of light brown (`#D6A77A`), and a background color of cream (`#FFF4E6`).
*   **Typography:** The app uses the `google_fonts` package to implement the Poppins font for headings and the Montserrat font for body text, creating a clean and modern look.
*   **UI Components:** The app utilizes Material Design 3 components, with custom styling for buttons, cards, and the app bar to create a unique and branded experience.
